Setup

  1. Set TELEGRAM_BOT_TOKEN in .env at the repository root (from @BotFather).
  2. Link an agent to your Telegram chat ID below (message @userinfobot or inspect bot updates).
  3. Local dev: set TELEGRAM_USE_POLLING=true (no ngrok), or point webhook to {{ request.url.scheme }}://{{ request.headers.get('host') }}/webhooks/telegram with optional TELEGRAM_WEBHOOK_SECRET.
  4. 5-agent pipeline: message your bot /launch (optional custom brief after the command). Final copy is sent back on Telegram when the run completes. Use /help for commands.
  5. Persistence: links are stored in PostgreSQL. With Docker Compose, data lives in the postgres_data volume (host postgres:5432 inside containers). Avoid docker compose down -v unless you intend to wipe the DB. If links vanish, you may be on a different DATABASE_URL than when you linked.
